# 回合回溯 v0.1.31 (PC v0.111.0)

## 修复

- 恢复能力时通过 `PowerModel.Target` 属性写回目标，并按 `CombatId` 解析目标与施加者。
- 沙坑能力的目标缺失时，以当前玩家角色为兜底，避免回溯后计时递减的空引用卡住战斗。

## PC 实战验证

- 在隔离的 PC v0.111.0 副本进入无厌沙虫 Boss 战。旧版 v0.1.30 从第 3 回合回到带沙坑 4 的第 2 回合后，结束回合稳定复现 `SandpitPower.get_AllAffectedCreatures()` 空引用，战斗停止推进。
- 最终 v0.1.31 构建在相同流程中，角色生命从 58/80 恢复至 74/80，沙坑从 3 恢复至 4；结束回合后沙虫正常攻击，生命变为 58/80，沙坑降至 3，并进入第 3 回合。日志中无战斗循环异常。
- 短按节点不回溯；拖动面板背景只改变整条回溯 UI 的位置。长按通过隔离测试辅助模组向真实 UI 节点发送按下和释放事件，未模拟物理鼠标持续按住或 Android 触控。
- 37 项离线断言通过。Android 版本未编译或实测。

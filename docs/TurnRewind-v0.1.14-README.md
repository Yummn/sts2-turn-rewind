# 回合回溯 / TurnRewind v0.1.14

## 修复

- 快照现在保存生物实例、CombatId、精确顺序和下一生物 ID。
- 回溯时会删除快照之后生成的怪物，并重新加入快照时存在但后来死亡或离场的怪物。
- 怪物模型节点会按恢复后的生物列表重建，避免模型数量与战斗逻辑数量不一致。
- Buff/Debuff 不再使用 `ToMutable(saved.Amount)` 在 Owner 为空时提前修改层数。
- 状态现在按“创建 0 层实例 → 绑定 Owner → 静默应用层数”的顺序恢复，并恢复 `AmountOnTurnStart`、持续时间跳过标记、施加者和目标。

## 验证

- PC v0.107.1 实战自动回归通过。
- 测试主动移除快照怪物并额外生成两只怪物，使生物数量从快照的 2 变成 3；回溯后恢复为原来的 2 个实例和原顺序。
- 力量恢复为 3 层、回合开始值 2；易伤恢复为 2 层、回合开始值 1；持续时间标记均正确。
- PC v0.107.1 与 Android v0.103.2 分别编译成功。

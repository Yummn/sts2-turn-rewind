# 回合回溯 v0.1.26

## 修复

- 精确保存并恢复每张战斗卡牌的基础费用、X 值和完整本地费用修正链。
- 修复带刺手甲等“全局增加费用”遗物在回溯时被写入一次临时费用、随后又被全局钩子再次增加，导致费用多加一次的问题。
- 能力恢复改为直接重建快照中的能力实例与数值，不再重新执行 `BeforeApplied` 等玩法施加钩子。
- 修复柔韧等临时力量/敏捷能力在回溯后标记消失、数值重复结算或回合结束无法正确撤销的问题。

## 验证

- Android v0.110.1 与 PC v0.107.1 均通过 Release 编译，0 警告、0 错误。
- 已核对 v0.110.1 与 v0.107.1 的 `CardEnergyCost` / `LocalCostModifier` 结构一致。
- 当前 ADB 未检测到设备，因此本次未声称完成手机实机运行验证。

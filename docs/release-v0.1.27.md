# 回合回溯 v0.1.27

## 同类效果检查

- 检查了 Android v0.110.1 游戏程序集中的全局费用修正：带刺手甲、借来的时间、缠绕、好奇、腐化、免费攻击/技能/能力、虚无形态及相关遗物。全局费用仍由游戏钩子按当前遗物和能力计算；快照只恢复卡牌自身的本地费用层。
- 检查了临时力量、敏捷、集中三组能力及其正负变体，包括柔韧药水、束缚、热修复、同步等。它们的临时标记和实际属性能力均由同一生物快照恢复。
- 发现星能费用也有基础费用、临时费用和全局费用三层。之前仅精确保存能量费用；本版增加星能费用的基础值、升级状态和按顺序排列的临时修正，恢复后仍由游戏全局钩子计算最终费用。
- 更正上版说明：`PowerModel.ApplyInternal` 自身不会调用 `BeforeApplied`。当前直接重建能力的原因是避免在能力尚未挂入生物列表时触发金额变化通知；临时属性和临时标记作为两个独立能力一起恢复。

## 验证范围

- Android v0.110.1、PC v0.107.1：Release 编译成功，0 警告、0 错误。
- 已核对两版程序集具有本次使用的星能费用类型和字段。
- 当前 ADB 未连接，也未完成真实对局回溯测试；本次结论为源码/程序集检查与编译验证。

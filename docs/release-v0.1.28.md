# 回合回溯 v0.1.28

## 修复

- 能力快照新增 `_internalData` 内的简单计数字段，以及 `DynamicVars` 的基础、附魔、预览数值。恢复时先写回这些状态，再将能力挂回生物。
- 修复储君「环绕轨道」回溯后回能进度重置为 4 点的问题；恢复其已花费能量与触发次数。
- 修复「虚空形态」回溯后免费出牌计数归零、导致后续卡牌持续 0 费的问题。
- 同一路径覆盖「自动化」「野性」等能力的内部计数，以及「华丽收场」等动态数值。

## 验证

- PC v0.107.1：真实战斗中注入上述能力，调用游戏原版「王者之踢」抽牌钩子，捕获快照、改变状态并执行真正的回溯。验证环绕轨道剩余 2 点、虚空形态已计数 2 张、自动化剩余 6 张、野性已计数 1 张、华丽收场动态数值 3，以及王者之踢本地/全局费用 3/3；测试输出 `PASS`。
- Android v0.110.1：对应程序集 Release 编译成功，未在手机实战测试。
- 王者之踢的本地费用快照路径来自 v0.1.26；本版通过实战回归验证，而非新增专用补丁。
- 对其他拥有简单计数的能力和本地费用修正卡进行了同路径代码检查；含卡牌引用字典等复杂内部结构不在此次通用快照范围内，未声称逐张实战通过。

# 回合回溯 v0.1.32

## 更新

- 为 Android v0.111.0 使用该版本手机游戏程序集重新构建，包含沙坑计时目标重绑定和结束回合状态恢复。
- 回溯前仅清理能力的表现层订阅与旧图标，不执行能力移除回调。修复旧状态图标残留并与恢复后的图标重复显示的问题，同时避免错误触发沙坑吞噬。
- 保留长按回溯、拖动整条 UI 移位。默认回溯条位于遗物栏下方。

## 2026-10-09 Android 真机验证

环境：Redmi K80 Pro，游戏 v0.111.0，启动器 v0.1.9。通过 ADB 实际触控，不是 PC 无头模拟。

1. 无厌沙虫战推进至第 3 回合，生命 69/87、沙坑计时 2。
2. 长按 T2，恢复第 2 回合：生命 84/87、能量 3、手牌 5、沙坑计时 3；仅显示一个沙坑图标，没有旧计时图标残留。
3. 结束回合后沙虫正常攻击，生命回到 69/87，沙坑计时降至 2，正常进入第 3 回合。
4. 打出电击，能量 3 → 2，生成第二个闪电球，手牌 5 → 4，弃牌 15 → 16；卡牌未悬停，战斗仍可操作。
5. UI 源码未改变的 v0.1.31 手机构建另验证了短按不回溯、拖动背景移动整条面板、移位后长按仍可回溯。

本轮未把此结果外推到沙坑计时归零、所有怪物或所有模组组合。PC v0.1.31 有独立沙虫实战记录；v0.1.32 的图标清理本轮仅在手机可见实测。离线断言属于结构审计，不代替真实战斗验证。

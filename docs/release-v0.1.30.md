# 回合回溯 v0.1.30

## 修复

- 回溯节点恢复为长按触发，短按不会回溯。
- 拖动回溯条只移动整个面板，不再沿途选择回合；长按过程中移动超过阈值会取消回溯并转为移动面板。
- 默认位置下移到顶部遗物和状态栏下方，且限制面板不会被拖出屏幕。
- v0.111 的回合状态从 `CombatManager._turnState` 清理：结束回合准备集合、敌方回合阶段标记、待处理失败状态，并将 `ActionQueueSynchronizer` 恢复到 `PlayPhase`，修复回溯后点击结束回合卡死。
- 移除恢复沙虫能力时对 `SandpitPower.UpdateCreaturePositions()` 的异步调用，避免旧时间线的异步位置任务在回溯后继续运行。

## 验证边界

- 已修改源码并进行 v0.111 引用兼容编译准备。
- 未把“沙虫回溯后结束回合”和“手机触控拖动面板”描述为已实机通过；需要在对应游戏窗口中复测。
